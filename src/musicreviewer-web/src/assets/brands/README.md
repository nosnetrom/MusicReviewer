# Streaming service icons

Used on the "Listen" buttons of recording pages, each linking to that service.

| File                | Source                                                                                           | Notes                                                             |
| ------------------- | ------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------- |
| `youtube-music.svg` | [Simple Icons](https://simpleicons.org) 16.33.0, `youtubemusic` (CC0)                            | Brand colour `#FF0000` added to the path                          |
| `pandora.svg`       | [Simple Icons](https://simpleicons.org) 16.33.0, `pandora` (CC0)                                 | Brand colour `#224099` added to the path                          |
| `amazon-music.png`  | Amazon Music's own site icon (`m.media-amazon.com/images/G/01/music/logo/1.0/smile_256x256.png`) | Scaled from 256px to 64px; Amazon's logos are not in Simple Icons |
